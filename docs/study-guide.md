# 学习功能

## 开始学习

1. 在词典详情点击“加入学习”，或首页“学习 · 今日任务”中选择多个词条加入。
2. 收藏与学习分开。加入学习不会立即算作已学，也不会自动加入全部词条。
3. 今日任务优先安排已到期的旧词，再安排新词。默认每天 5 个新词，可设为 1—50 个，也可暂停新词。
4. 点击“开始学习”，先看竖排蒙古文，自行回忆含义，再点击“显示答案”。
5. 转写默认隐藏。查看转写或听发音提示后，本次只能选择“忘记了”或“费力想起”。显示答案后听音不扣评分。
6. 答案默认显示原释义的首段（按冒号、义项②或分号截取），不是另行生成的解释。可展开完整释义与例句。当前不支持选择特定义项学习。
7. 根据实际回忆表现评分。可撤销本次会话的最后一次评分；关闭页面/重新启动后不提供上次会话的撤销。

## 当前复习规则

本版使用简单、可解释的间隔调度，并非 FSRS，也不声称预测个人遗忘概率：

- 忘记了：1 分钟后到期，进入重新学习。
- 费力想起：首次 1 天；以后前次间隔乘 1.2 向上取整。
- 记得：首次 1 天；以后前次间隔乘 2。
- 很轻松：首次 3 天；以后前次间隔乘 2.7 向上取整。
- 间隔最多 365 天。评分按钮显示本次实际安排。
- 时间以设备时间为准；每日新词限额按设备本地日期计算，复习日期按评分时间加间隔计算。
- “当前任务已完成”只表示此时没有到期卡。1 分钟后可点“刷新今日任务”继续，或再次点击开始学习。

同一词的学习状态关联永久 ID，文字或音频更新不重置进度。当前只有看文回忆模式；听音专项、拼写判分、词尾训练、命名词表及 FSRS 尚未实现。学习记录保存每次评分、时间及是否使用提示，方便后续升级。

## 暂停和备份

在“学习词表”可暂停/恢复单词，已有进度保留。修改每日新词设置或词表后，上一评分的撤销入口会清除。

词典首页 → 导入 / 导出词库 → “导出词库、语音和学习进度 ZIP”。包里增加 `study.json`，包含学习状态、设置及评分历史。

普通“导入词库 ZIP”只更新词库；不会覆盖学习进度。恢复时先导入对应词库，再选择“从 ZIP 恢复学习进度”。确认后会替换当前整套学习进度与设置；它不是两份进度的合并。恢复前建议先导出当前版本。收藏目前不包含在 ZIP 备份中。

## 验收重点

- 加入 2—3 个自己要学的词，检查题面不泄露转写或中文答案。
- 使用提示后，两档最高评分应不可选。
- 评分后离开并重开，任务数量和复习时间应保留。
- 撤销评分后，卡片及当天新词名额应恢复。
- 有录音的词可以播放，没录音的词也可以正常学习。
- 导出后从 ZIP 恢复学习进度，核对词数和设置。

## 日历、整组选词与复制

- 今日学习 → 学习日历：月历颜色表示当天完成评分的不同词条数量（0 / 1—4 / 5—9 / 10—19 / 20+）。同词当天多次评分只占一个词数；点击日期另看练习次数、新学和复习，后两者可能重叠。加入词表或只翻看不计数，撤销评分也撤销对应记录。月累计为每日去重数之和，并非全月去重词数。
- 新评分保存当时的本地日期，避免旅行改变时区后日期移动。旧历史没有日期字段，首次读取时按当时设备时区推导；在下一次保存或备份中保留。
- 随机选词：抽取 1/3/5 组未全部加入的词组，预览后“加入整组”，可“换一批”。手选和词典详情加入也会扩展到整组。已学习/暂停的状态保持不变，重复加入不会重置进度。仍按每日新词上限逐日学习。
- 分组优先使用 CSV 可选列 `family_id`。同组成员需填写相同值；未填写时按转写的第一个完整词头（空白或短横线前）归组，保留大小写。它是保守的检索分组规则，不是自动语法分析。
- 例如 kereg 组包含已收录的 kereg e kereg、kereg-iyen daruqu 等；不会仅凭字母前缀纳入 kerege/kereglekU。派生词若希望同组，可人工填写 family_id。相关短语必须已经存在于词库中，不能自动补出未导入的内容。
- 竖排蒙古文/释义区域：长按复制整段原文。复制的是原字符（保留 NNBSP/MVS/FVS），不是竖排括号的显示替换字形。当前竖排不支持拖动选择局部文字。
- 横排转写：支持系统长按选择。搜索列表长按词条，可以选择复制蒙古文、转写、释义或整个词条。
