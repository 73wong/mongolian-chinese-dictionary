## 中文

本次更新聚焦启动速度、搜索体验与词条纠错。

- 使用 SQLite 索引按需读取词条，减少启动及页面切换时整库解析；部分词表处理移到后台。
- 简化搜索首页与筛选面板，加入居中的传统蒙古文标题，统一标题为 Monggol Hitad Toli。
- 全文搜索使用部分匹配，保留转写模糊查询；精简搜索状态标签与导航样式。
- 合并重复的 mori(n) 词条，迁移收藏和学习记录。
- 修正 11 条 cengk / cengg 开头词条的音标，将对应 tʃiŋ… 改为 tʃəŋ…；未给缺失字段生成音标。
- 更新中英文 README、构建与验证说明。

### 安装

下载 `mongolian-chinese-dictionary.apk`，内置 53,413 条词条与已有离线录音，支持 Android 8.0 及以上。沿用原调试签名，建议先备份个人记录，再覆盖安装，不必卸载旧版。

版本：`1.1.2-offline`，versionCode：`18`。首次启动会复制并校验数据库，后续复用索引；本次索引会增加安装体积和存储占用。没有新增 AI 语音。

开发者继续使用 [v1.1.0 dictionary-data.zip](https://github.com/73wong/mongolian-chinese-dictionary/releases/download/v1.1.0/dictionary-data.zip)，构建时自动应用修正并生成索引。普通用户无需另下数据包。

## English

This update focuses on startup, search and dictionary corrections.

- Load entries on demand through SQLite indexes, reducing full-dictionary parsing; move selected vocabulary operations off the UI thread.
- Simplify the search home and filter sheet; add a centered traditional Mongolian wordmark and use Monggol Hitad Toli consistently.
- Use contains matching for full-text search while retaining optional transliteration equivalences.
- Merge duplicate mori(n) entries and migrate favorites and study records.
- Correct the IPA of 11 cengk / cengg entries from tʃiŋ… to tʃəŋ…; leave missing pronunciations unchanged.
- Refresh bilingual documentation and build instructions.

Download `mongolian-chinese-dictionary.apk`. It contains 53,413 entries and available offline recordings. Android 8.0+; versionName `1.1.2-offline`, versionCode `18`. The existing debug signing key is retained. Back up personal records before upgrading in place.

The first launch copies and verifies the database; later launches reuse it. Indexing adds package and storage overhead. No synthetic audio has been added. Developers can reuse the v1.1.0 data archive linked above.
