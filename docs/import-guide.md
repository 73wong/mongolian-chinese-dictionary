# 词条和语音导入格式

## 包格式

ZIP 根目录必须是 `entries.csv`；音频放在 `audio/` 下，不要在外面多套一层文件夹。

```
entries.csv
audio/kereg.mp3
```

CSV 使用 UTF-8（可带 BOM）。推荐先导出再编辑。字段可以有逗号、双引号或换行，但必须按 CSV 标准引用；不要手动删除蒙古文里的不可见控制字符。音频支持文件扩展名 mp3、wav、m4a、ogg；实际编码必须能被 Android 解码，扩展名正确不保证声音可播放。

| 列 | 用法 |
| --- | --- |
| id | 必需。已有词条保持原 ID；新增使用新的唯一 ID，如 `user-20261008-001`。只允许英文字母、数字、短横线和下划线，最多 100 字符 |
| mongolian | 新词必需，传统蒙古文原文 |
| transliteration | 新词必需，保留空格及有意义的大小写 |
| definition | 新词必需，释义；目前例句仍与释义合并 |
| source_page | 来源页码或段号 |
| pronunciation / pronunciation_extra | 可选的音标及附加读音信息 |
| audio_file | 包内路径，例如 `audio/kereg.mp3`；留空不删除旧音频 |
| audio_source | 录音者、来源链接或其他来源说明 |
| saved_page | 原抓取批次页码，可留空 |
| references / audio_urls | 可选 JSON 字符串数组，普通新增可留空；链接仅保留元数据，不自动联网下载 |

仅补语音时，CSV 只需 id、audio_file、audio_source 三列。修改释义可只提供 id、definition。**空白值表示保留旧字段，不表示清空。** 当前不支持批量删除或清空字段。

在 Mac 上新增：复制模板、填写新 ID 和必填字段，保存为 UTF-8 CSV 并命名 `entries.csv`；如有录音，与 audio 文件夹一起压缩。导入先看新增/更新数量和前 8 项词条预览，疑似同词不同 ID 会提示。不同 ID 不会自动合并，因为同形词也可能是独立词条。

永久 ID 用于关联收藏；已有基于文字的收藏会自动迁移。以后更新文字时请沿用 ID，背单词进度也将使用同一 ID。

## 当前范围和限制

- 每词支持一条词条语音；例句语音、多朗读者和 App 内录音按钮尚未实现。
- 导入限制：每个文件最大 20 MB、整个包解压后最大 64 MB、最多 300 个文件，可分批处理。
- 检查失败或取消预览不会更新词库。数据和语音保存在应用私有目录；卸载会删除，先导出备份。
- 预览并不验证蒙古文语法正确，也不验证音频内容与词条一致；这仍需人工验收。
